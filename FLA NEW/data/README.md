# Dataset Documentation: Spam Email Detection

## 1. Verified Kaggle Source
- **Dataset Title:** Spam Email Detection Dataset (Clean & ML Ready)
- **Author:** Thanh Nhan Nguyen (`ssssws`)
- **Direct Kaggle URL:** [https://www.kaggle.com/datasets/ssssws/spam-email-detection-dataset-clean-and-ml-ready](https://www.kaggle.com/datasets/ssssws/spam-email-detection-dataset-clean-and-ml-ready)
- **Original Downloaded File Name:** `spam_email_dataset.csv`
- **Active Project File Location:** `data/dataset.csv`

---

## 2. Dataset Properties
- **Total Records:** 10,000 emails
- **Spam Count (Label 1):** 3,995 (39.95%)
- **Ham Count (Label 0):** 6,005 (60.05%)
- **Primary Text Column:** `email_text`
- **Primary Label Column:** `label`
- **Class Encoding:**
  - `1` = **SPAM** (Malicious, promotional, high-urgency, or financial solicitation)
  - `0` = **HAM** (Legitimate business, university, sync, and project communications)
