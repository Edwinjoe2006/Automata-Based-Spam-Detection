Academic Discussion & Critical Findings

Advantages of Automata-Based Systems:

  • Mathematical Provability: Every decision stems from a state progression sequence that can be mathematically verified in JFLAP.
  • Zero Cold-Start: Does not require thousands of labelled training examples or model re-training cycles.
  • Ultra-Low Resource Footprint: Runs in linear time $O(N)$ with trivial memory utilization, suitable for embedded gateway filtering.

Limitations & False Negative Analysis:

  • Heuristic Boundaries: Hand-crafted automata rules cannot anticipate all creative obfuscations (e.g., character insertions or zero-width spaces).
  • Corpus Generalization: Unlike ML classifiers which continuously update statistical priors, rule sets require manual curation.
  • False Positives: Legitimate emails discussing "free slots" or "account verification" can occasionally trigger rules if context is ignored.
