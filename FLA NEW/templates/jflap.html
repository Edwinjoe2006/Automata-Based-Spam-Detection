JFLAP Automata Models & Specifications

This project is built directly for JFLAP. Both the NFA and DFA models are pre-saved as ready-to-open .jff files inside the jflap/ folder, and can also be recreated manually in JFLAP using the 7 simple steps below.

How to Open & Run in JFLAP (Instant Method)

1
Launch JFLAP:

Go to your project's jflap/ folder and double-click JFLAP7.1.jar (or run java -jar jflap/JFLAP7.1.jar in terminal).

2
Open the Automaton:

In the JFLAP menu bar, click File → Open, then select:

  • jflap/spam_nfa.jff — for the Non-deterministic Finite Automaton
  • jflap/spam_dfa.jff — for the Deterministic Finite Automaton
3
Simulate Strings:

Click Input → Step with State... or Input → Fast Run... and test strings like W F P (Accepted → Spam) or F (Rejected → Ham).

Manual JFLAP Creation Guide (For College Viva & Lab)

  1. Open JFLAP: Launch JFLAP and click Finite Automaton from the startup menu.
  2. Create States: Select the state creation tool (circle icon) and click on the canvas to create 3 states: q0, q1, and q2 (or S0, S1, S2).
  3. Mark Initial State: Switch to the arrow tool, right-click on q0 (or S0), and check Initial.
  4. Mark Final State: Right-click on q2 (or S2), and check Final.
  5. Add Transitions: Select the transition tool (arrow icon) and draw transitions for each symbol in Σ = {F, W, P, O, U, C, K, B}:
    • From q0 → q1 on F, W, P, O, U, C, K, B
    • From q1 → q2 on F, W, P, O, U, C, K, B
    • Self-loop on q2 → q2 on F, W, P, O, U, C, K, B
  6. Convert NFA to DFA inside JFLAP: Go to Convert → Convert to DFA in the JFLAP menu to view JFLAP's internal subset construction!
  7. Test Strings: Go to Input → Multiple Run to test accepted vs rejected strings.

Formal Mathematical Definitions (5-Tuple)

NFA Definition M = (Q, Σ, δ, q0, F)

  • States (Q): { q0, q1, q2 }
  • Alphabet (Σ): { F, W, P, O, U, C, K, B }
  • Initial State (q0): q0
  • Final States (F): { q2 }
  • Language Recognized: L = { w ∈ Σ* | |w| ≥ 2 }
  • Regular Expression: r = Σ Σ Σ*

DFA Definition M' = (Q', Σ, δ', S0, F')

  • DFA States (Q'): { S0, S1, S2 } where S0={q0}, S1={q1}, S2={q2}
  • Alphabet (Σ): { F, W, P, O, U, C, K, B }
  • Initial State: S0
  • Final States (F'): { S2 } (Accepted &implies; SPAM)
  • Non-Final States: { S0, S1 } (Rejected &implies; HAM)

NFA → DFA Subset Construction (Powerset Construction)

Every NFA state subset forms a deterministic state in the DFA:

DFA State NFA State Subset Input Symbol a ∈ Σ Next DFA State Accepting? Classification
S0 (Initial) { q0 } Any a ∈ Σ { q1 } = S1 No HAM (0 keywords)
S1 { q1 } Any a ∈ Σ { q2 } = S2 No HAM (1 keyword)
S2 (Accepting) { q2 } Any a ∈ Σ { q2 } = S2 Yes SPAM (≥2 keywords)

Accepted vs Rejected String Examples in JFLAP

Accepted Strings (SPAM &implies; Final State S2)

  • W F P (Length 3 ≥ 2) → "Winner Free Prize"
  • C B (Length 2 ≥ 2) → "Claim Bonus"
  • U O W (Length 3 ≥ 2) → "Urgent Offer Winner"
  • W P C (Length 3 ≥ 2) → "Winner Prize Claim"
  • K C B (Length 3 ≥ 2) → "Click Claim Bonus"

Rejected Strings (HAM &implies; Halted in S0 or S1)

  • ε (Empty string, Length 0) → No keywords detected
  • F (Length 1 < 2) → Only isolated word "free"
  • K (Length 1 < 2) → Only isolated word "click"
  • O (Length 1 < 2) → Only isolated word "offer"
  • U (Length 1 < 2) → Only isolated word "urgent"
